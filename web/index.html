Entrar

Login simulado. As contas ficam só neste navegador (a senha é guardada como hash, nunca em texto). Serve para demonstração e não protege os dados de quem usa este computador.

Conta de demonstração: demo / finguia

Abra o banco do FinGuia

Arraste o arquivo finguia_database aqui, ou clique para escolher. Nada é enviado para a internet — o arquivo é lido dentro do seu navegador.

Como exportar o banco do celular

Com o aparelho conectado e a depuração USB ativa, rode na pasta do projeto:

web/exportar-banco.bat

O script usa adb para copiar o banco do app para web/dados/.
